# 📊 Análise da Demanda por Bicicletas Compartilhadas

Projeto desenvolvido para a disciplina de **Visualização de Dados**, utilizando o **Bike Sharing Dataset**.

## 🎯 Objetivo

Investigar, por meio de visualizações de dados, quais fatores estão relacionados à demanda por bicicletas compartilhadas.

## 🔎 Perguntas investigativas

* Em quais horários ocorre a maior demanda por bicicletas?
* A demanda apresenta diferenças entre dias úteis e dias não úteis?
* Existe relação entre temperatura e quantidade de bicicletas alugadas?
* Como as condições climáticas estão relacionadas à demanda?

## 🛠️ Tecnologias utilizadas

* Python
* Pandas
* Plotly
* Google Colab
* Jupyter Notebook

## 📈 Visualizações

Foram desenvolvidos quatro tipos diferentes de gráficos:

* Gráfico de linha
* Box Plot
* Gráfico de dispersão
* Gráfico de barras

Além disso, cada visualização foi comparada entre sua versão padrão e uma versão customizada, buscando melhorar a interpretação e comunicação dos dados.

## 📂 Dataset

**Bike Sharing Dataset**

Fonte: Kaggle

O dataset contém informações sobre o uso de bicicletas compartilhadas durante os anos de 2011 e 2012, incluindo dados de horário, temperatura, umidade, condições climáticas e quantidade de bicicletas alugadas.

## 📁 Arquivos

* `hour.csv` — dataset utilizado na análise
* `*.ipynb` — notebook com todo o processo de análise e visualização
